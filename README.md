# DAGR MCP

<!-- layer-map -->

| Role | Surface |
|---|---|
| Standard | ARCS |
| Receipt protocol and profiles | SRS |
| Open runtime and adapters | DAGR |
| Public reference implementations | DAGR MCP and ARCS Verify |
| Public read and demo surfaces | GARPedia, Overlay, Showcase |
| Commercial operator products | Countervail, Workbench, managed deployments |

MCP is DAGR's first supported binding. This package is the public-canonical MCP-shaped admission runtime and signed SRS emitter. It does not claim to be a transport-neutral runtime.

The receipt path is raw-content-excluding: DAGR-owned envelopes and sinks accept references and digests, not governed arguments, results, credentials, or private paths.
